# Power BI Project File

This folder contains the Power BI Desktop project file for the MavenTech CRM Sales Operations Analysis portfolio project.

The `.pbix` file includes the data model, DAX measures, report pages, interactive filters, bookmarks, field parameters, dynamic visual elements, drill-through functionality, tooltips, and other analytical features demonstrated in this project.

> **Note:** Microsoft Power BI Desktop is required to open and interact with the `.pbix` file.
